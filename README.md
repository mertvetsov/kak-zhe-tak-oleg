# Как же так, Олег

Играбельная ретро LCD-игра. Готовая версия сайта находится в папке `dist/`.

## Как заменить спрайт

1. Откройте папку `dist/assets/`.
2. Выберите нужный PNG-файл и нажмите **Edit / Upload files**.
3. Загрузите новый файл с тем же именем.
4. Сохраните изменение в ветку `main`.

Сохраняйте размер холста, прозрачность и положение персонажа внутри изображения — игра использует заданные области обрезки и масштаб.

## Локальный запуск

Откройте `dist/index.html` через любой статический HTTP-сервер.
