# Как же так, Олег

Играбельная ретро LCD-игра. Исходники опубликованной версии находятся прямо в корне репозитория.

## Как заменить спрайт

1. Откройте папку `assets/`.
2. Выберите нужный PNG-файл и нажмите **Edit / Upload files**.
3. Загрузите новый файл с тем же именем.
4. Создайте отдельную ветку и Pull Request.

Сохраняйте размер холста, прозрачность и положение персонажа внутри изображения — игра использует заданные области обрезки и масштаб.

## Как изменить реплики Олега

Все случайные восклицания лежат в `resources/oleg-exclamations.json` и разделены на три группы:

- `catch` — обычная успешная поимка;
- `unicorn` — поимка единорога;
- `toxic` — поимка токсичного актива.

Редактируйте только текст внутри кавычек и сохраняйте корректный JSON.

## Локальный запуск

Из корня репозитория запустите статический HTTP-сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Напрямую через `file://` игра не запустится, потому что файл реплик загружается через `fetch`.

Перед локальным коммитом запустите применимые проверки:

```bash
node --check game.js
node tests/smoke_game_runtime.js
python3 tests/verify_sprite_animation_v3.py
git diff --check
```

Обычные правки выполняются в отдельной локальной ветке от актуального `main`. Ветка отправляется на GitHub только когда нужна ссылка для проверки: Pull Request в `main` запускает workflow `Publish PR preview`, который публикует временную версию по адресу `/pr-preview/pr-<номер>/`. Объединение с `main` и выпуск выполняются только после явного одобрения.

Основная опубликованная версия: https://mertvetsov.github.io/kak-zhe-tak-oleg/
